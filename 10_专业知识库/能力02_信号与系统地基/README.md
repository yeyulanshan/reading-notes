# 能力 02 · 信号与系统地基

**这一个能力的定位与能力 01 不同：能力 01 是「换个工具」，这里是「补地基」。**

---

## 一、为什么单独立一个能力

**背景**：自动化专业，信号与系统学过但没学通。

**这不是"深化"，是"补地基"。** 区别很大：

| | 深化 | 补地基 |
|---|---|---|
| 前提 | 已经通了 | **没通** |
| 做法 | 往深处挖 | **把断的地方接上** |
| 风险 | 挖不动 | **从零重讲 → 读不下去** |

**所以这个能力不做三件事**：不从零讲、不列公式表、不按教材章序走。

**它只做一件事**：**先帮你定位哪一层没通，再给那一层的最小入口。**

**为什么它优先级最高**（呼应 `../结构决策.md` 的 P1）：

> 信号与系统是**中枢**。它是电路里的阻抗、控制里的传递函数、
> 滤波器设计的依据、DSP 的基础、深度学习里卷积的来源。
> **它不通，后面所有方向都是悬空的。**

## 三、核心产出：同一个系统的五张脸

### 它在解决什么问题

信号与系统学不通，最常见的症状**不是某公式没记住**，而是：

> "我会算拉普拉斯变换，也会算差分方程，也会画波特图，
>  **但它们是同一个东西**这件事，我没真正感觉到。"

于是这门课变成四五个互不相干的工具箱：微分方程一套、拉普拉斯一套、
差分方程一套、z 变换一套、傅里叶一套……

### 它做了什么

拿**一个**物理系统（一阶 RC 低通，τ = 1 ms），把它的**五张脸**都算出来：

| 脸 | 表示 | 形式 | 算出的特征量 | 实测数值 |
|---|---|---|---|---|
| ① | **时域** | `RC·dy/dt + y = u` | 时间常数 τ | **1.000 ms** |
| ② | **频域** | `H(jω) = 1/(1+jωRC)` | 截止频率 fc | **159.1549 Hz** |
| ③ | **s 域** | `H(s) = 1/(1+sτ)` | 极点 s_p | **−1000 rad/s** |
| ④ | **z 域** | `y[n] = 0.952381·y[n−1] + 0.047619·u[n]` | z 极点 | **0.952381** |
| ⑤ | **状态空间** | `dx/dt = −x/τ + u/τ` | 特征值 λ | **−1000 rad/s** |

**然后证明它们是同一件事**：

```
τ = 1/ωc = −1/s_p = −1/λ = −T/ln(z_p)
```

**实测验证**（脚本 exit=0）：
- z 极点 0.952381 vs 理论 e^(−T/τ) = 0.951229（差 1.15e-03，是离散化误差）
- 状态空间特征值 −1000 rad/s **完全等于** s 域极点
- 同一个阶跃响应，解析解与差分方程解的偏差在 1e-7 ~ 5e-3 之间（随 T 减小而减小）

### 为什么"都要跑一遍"

**因为"把五张脸串起来"这件事本身就是解药。**

哪怕你诊断出自己 A 组弱（时域）、C 组弱（频域），
**先看一遍这五个数如何互相换算**，后面学任何一个具体章节都会更容易——
因为你已经知道那块拼图在整个图里的位置。

### 一个刻意加入的设计

脚本最后有**三个极限检验**（C→0、C→∞、R→0 时电路退化成什么）。

**这是给你自己检查理解用的**：把参数改成极端值重跑，
如果结果不符合直觉，就找到了薄弱点。

**这比"重读一遍课本"有效**，因为它强制你**做出可被推翻的预测**
—— 这和 `07_技术/动手实验` 那条纪律是同一件事。

## 五、我在这份产出里的一个推测（你可以反驳）

**我的判断是：大多数人"没学通"的症状落在 B 组（复频域）和 C 组（频域），
但根因常在 A 组（时域与卷积）。**

理由：**A 组是唯一一个"动手就能验证"的层**——你可以在纸上算卷积，
也可以用数值积分验证。而如果这一层是靠背公式过的，
后面所有变换都会变成"另一套公式"，于是这门课就分裂成了几个工具箱。

**所以我把"五张脸"做成了第一个产出，而不是从 A 组开始讲。**
因为"串起来"比"补齐某一层"更能破解"分裂成工具箱"这个症状。

**如果你跑完发现症状和我的推测不符，那正好——诊断的价值就在这里。**

**一个值得注意的细节**：MIT 6.003 的教材**从差分方程讲起**（chap1 是 "Difference equations"），
而不是从连续时间信号讲起。这和多数国内教材的顺序相反。

**这个顺序对"没学通"的人可能更友好**——因为差分方程是可以用手算、用代码验的最简单的形式，
而把"系统"这个概念建立起来之后，再看连续时间就不会那么抽象。

（顺带：这也解释了为什么 `能力01` 里那个"分压电路 + RC + RLC"的路径是有效的
——它是**从电路这个具体东西出发**，而不是从抽象定义出发。）
