# 第二部分 · 翻译表：同一件事的五种说法

**这张表是能力 02 的核心工具。**
左边是你的问题，右边是五种表示各自怎么回答。

## 2.1 概念对照

| 概念 | 时域说法 | 频域说法 | s 域说法 | z 域说法 | 状态空间说法 |
|---|---|---|---|---|---|
| **系统的"身份"** | 冲激响应 h(t) | 频率响应 H(jω) | 传递函数 H(s) | H(z) | (A, B, C, D) |
| **"快慢"** | 时间常数 τ | 截止频率 ωc=1/τ | 极点实部 −1/τ | 极点 \|z\|=e^(−T/τ) | 特征值 λ=−1/τ |
| **"振荡"** | 衰减振荡的周期 | 谐振峰的位置 | 极点的虚部 ±jωd | 极点的辐角 | 特征值的虚部 |
| **"稳定性"** | h(t)→0 | （不直接看） | 极点在左半平面 | 极点在单位圆内 | 特征值实部<0 |
| **"增益"** | 阶跃响应的终值 | \|H(0)\|（直流增益） | H(0) | H(1) | −CA⁻¹B+D |
| **"运算"** | 卷积 y=h*u | 相乘 Y=H·U | 相乘 Y=H·U | 相乘 Y=H·U | 矩阵运算 |
| **"输入输出关系"** | 微分方程 | H(jω)=Y(jω)/U(jω) | H(s)=Y(s)/U(s) | H(z)=Y(z)/U(z) | dx/dt=Ax+Bu |

**★ 看**"运算"**那一行**：时域是**卷积**，其他四个都是**相乘**。
这就是为什么要做变换 —— **变换把卷积变成了乘法**。
记住这一点，整个变换体系就有了统一的理由。

## 2.2 「同一个东西」的五个名字

以本项目的 RC 电路（τ = 1 ms）为例：

| 特征量 | 在哪张脸上 | 数值 | 换算 |
|---|---|---|---|
| 时间常数 | ① 时域 | τ = 1.000 ms | 基准 |
| 截止频率 | ② 频域 | fc = 159.15 Hz | fc = 1/(2πτ) |
| 极点 | ③ s 域 | s_p = −1000 rad/s | s_p = −1/τ |
| z 极点 | ④ z 域 | z_p = 0.9524 | z_p = e^(−T/τ) |
| 特征值 | ⑤ 状态空间 | λ = −1000 rad/s | λ = s_p（SISO 一阶） |

**反向换算（任意一个 → τ）**：

```
τ = 1/(2π·fc)          从频域
τ = −1/s_p             从 s 域极点
τ = −1/λ               从状态空间特征值
τ = −T / ln(z_p)       从 z 域极点
τ = t(63.2%)           从时域波形（示波器做法）
```

**★ 这六行就是"把五张脸缝起来"的线。建议手抄一遍。**

## 2.3 五种分析手段各自回答什么

| 你想知道 | 用什么 | 不要用 |
|---|---|---|
| 稳态直流值是多少 | s 域令 s→0（或 .op） | 傅里叶 |
| 快慢、超调、振铃 | 极点位置 | 傅里叶 |
| 对正弦输入的稳态响应 | 频率响应 H(jω) | 微分方程直接解 |
| 对任意输入的响应 | 卷积（或 s 域相乘） | 频率响应 |
| 采样后会怎样 | z 域 / DTFT | s 域 |
| 闭环稳不稳 | 根轨迹 / 波特图 / 特征值 | 时域仿真试错 |
| **数值上到底是多少** | **跑一遍代码或仿真** | — |

**★ 最后一行值得强调**：**前面所有"用什么"都是为了"不用试错"。**
而如果你不确定自己对不对，**最快的办法就是算一遍** ——
这正是 `能力02_四张脸.py` 在做的事。

# 第三部分 · 12 个常见误区（按"错在哪一层"分类）

## A 组 · 时域

### M1 · "卷积就是那个积分公式"
**错在**：把卷积当运算，没当**物理意义**。
**正确**：卷积 = "把输入拆成一串冲激，每个冲激产生一个衰减的响应，全部叠加"。
**检验**：你能不能**不用公式**、用"叠加"的直觉说出方波通过 RC 后为什么变成那样？

### M2 · "线性"和"时不变"混在一起
**错在**：以为是同一件事。
**正确**：**线性**（叠加原理）和**时不变**（延迟输入则延迟输出）是**两个独立条件**。
**反例**：`y(t) = t·u(t)` 是线性的但**时变**；`y(t) = u(t)²` 是时不变的但**非线性**。
**为什么重要**：传递函数、频率响应、卷积——**全都要求 LTI**。

### M3 · 忽略"零输入响应"和"零状态响应"的区别
**错在**：解微分方程时只算了一部分。
**正确**：完整解 = 零输入响应（初始条件引起的）+ 零状态响应（输入引起的）。
传递函数只描述**零状态**响应。

## B 组 · 复频域

### M4 · 忽略收敛域（ROC）
**错在**：只算 H(s) 的表达式，不看它在哪收敛。
**正确**：**同一个 H(s) 表达式配不同的 ROC，是不同的系统。**
**后果**：会得出"稳定系统不稳定"或反之的错误结论。

### M5 · 以为极点在左半平面"就是"稳定
**错在**：把它当定义背下来。
**正确**：那是因为极点在左半平面 → 对应的时域项是 e^(−σt) → 衰减到 0。
**检验**：如果极点在**虚轴上**呢？（临界稳定：不衰减也不发散，如纯积分器。）

### M6 · 把 z = e^(sT) 当"另一个公式"
**错在**：没看出它是**坐标变换**。
**正确**：
```
s 平面               z 平面
虚轴（jω）      →    单位圆
左半平面        →    单位圆内
右半平面        →    单位圆外
```
**所以**"s 左半平面稳定"和"z 单位圆内稳定"是**同一句话的两个坐标写法**。

## C 组 · 频域

### M7 · 混淆四种"傅里叶"
**错在**：把它们当同一件事。

| 名称 | 适用信号 |
|---|---|
| **傅里叶级数** | 连续、**周期** |
| **傅里叶变换** | 连续、**非周期** |
| **DTFT** | 离散、非周期（频域连续且周期） |
| **DFT** | 离散、**有限长**（频域也离散） |

**口诀**：**时域周期 ↔ 频域离散；时域离散 ↔ 频域周期。**

### M8 · 以为"频率响应"是新东西
**正确**：`H(jω)` 就是把 `H(s)` 里的 `s` 换成 `jω`。
而 `H(s)` 就是把微分方程里的 `d/dt` 换成 `s`。
**所以频率响应 = 微分方程在正弦输入下的稳态解**，不是新概念。

### M9 · 相位只是"一个角度"
**错在**：没理解相位的物理意义是**时延**。
**正确**：相位 −φ 在频率 ω 处等价于延迟 φ/ω。
**所以**相位非线性 → 不同频率延迟不同 → 波形失真（即使幅度没变）。

### M10 · 采样定理只记"两倍"
**错在**：只记 `fs > 2fmax`。
**完整条件**：① 信号**带限**（这本身就是个前提）；② `fs > 2fmax`；
③ **抗混叠滤波器**必须在采样前（而不是采样后想办法）。
**★ 第三条最常被忽略**，而现实中它才是关键。

## D 组 · 与控制连接

### M11 · 认为反馈只是"减小误差"
**正确**：反馈真正改变的是**极点位置**。
误差减小是极点移动的**结果**，不是原因。
**这也解释了为什么反馈可能让系统**不稳定**——它把极点推到了右半平面。

### M12 · 把"超调"当纯粹的时域现象
**正确**：超调由**阻尼比 ζ** 决定，而 ζ 由**极点的辐角**决定。
所以：
```
超调量  ←→  极点的辐角（与负实轴的夹角）
衰减快慢 ←→  极点到虚轴的距离（实部绝对值）
```
**一张极点图就同时告诉了你超调和快慢。** 这是控制里"看极点"的全部理由。

# 第四部分 · 极限检验（最实用的自学工具）

**当你不确定自己算得对不对，做极限检验。** 它比"重算一遍"有效得多。

| 检验 | 做法 | 该发生什么 |
|---|---|---|
| **参数极限** | C→0 / C→∞ / R→0 / R→∞ | 电路退化成导线或断路 |
| **频率极限** | ω→0 / ω→∞ | 电容呈开路 / 短路 |
| **时间极限** | t→0 / t→∞ | 初值 / 稳态值 |
| **增益极限** | 传递函数在 s→0 与 s→∞ | 应是有限值且符合物理 |
| **量纲检验** | 检查单位 | τ 必须是秒；ωc 必须是 rad/s |
| **因果检验** | 输出是否先于输入出现 | 因果系统不该有超前 |
| **稳定性检验** | 极点位置 | 物理无源系统应稳定 |

**★ 一个具体的例子（本项目 RC 电路）**：

```
C → 0   →   τ → 0   →   fc → ∞   →   |H| ≡ 1（全通）
C → ∞   →   τ → ∞   →   fc → 0    →   |H| ≡ 0（全阻）
R → 0   →   τ → 0   →   fc → ∞   →   |H| ≡ 1（全通）
```

**如果哪一条和你算的不一致，说明那里有错。**
