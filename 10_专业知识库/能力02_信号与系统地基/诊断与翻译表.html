能力 02 · 诊断 · 翻译表 · 误区排查

这份文件针对一个具体处境：信号与系统学过，但没学通。

所以它不做三件事：不从零讲、不列公式表、不按教材章序走。 它只做一件事：帮你定位到底哪一层没通，然后给那一层的最小入口。

第一部分 · 诊断：你在哪一层卡住

27 个自测题（按"表示"分组，不按教材章序）

用法：逐条问自己。能立刻答出来就打勾，模棱两可就当不会。 最后看哪个分组的勾最少 —— 那就是你的入口。

A 组 · 时域与卷积（对应 MIT 6.003 lec02/04/08）

  • [ ] 我能从 KCL 或分压自己列出 RC 电路的微分方程（不是背结论）
  • [ ] 我知道"线性"和"时不变"各自的定义，且能举一个不是LTI 的例子
  • [ ] 我理解卷积是"把输入拆成冲激、各自响应再叠加"，而不是一个积分公式
  • [ ] 我能解释为什么 LTI 系统完全由冲激响应决定
  • [ ] 我知道阶跃响应和冲激响应是积分/微分的关系

B 组 · 复频域（s 与 z）（对应 lec03/05/06/07）

  • [ ] 我能说清为什么要引入拉普拉斯变换（而不是只会算）

  • [ ] 我能从极点位置直接读出时间常数或振荡频率（不用反变换）
  • [ ] 我知道 z 变换与拉普拉斯变换的关系（z = e^(sT)），以及为什么
  • [ ] 我知道 z 平面单位圆内 = 稳定，且它与 s 左半平面是同一件事
  • [ ] 我能解释收敛域（ROC）为什么重要，以及忽略它会出什么错

C 组 · 频域与傅里叶（对应 lec09/11/14–20）

  • [ ] 我知道傅里叶级数、傅里叶变换、DTFT、DFT 四者的区别与联系
  • [ ] 我能解释频率响应 H(jω) 就是"把 d/dt 换成 jω"（而不是另一个公式）
  • [ ] 我能手画一阶低通的波特图（渐近线 + 转折点）
  • [ ] 我知道相位的物理意义（时延），而不只是"一个角度"
  • [ ] 我理解采样定理的完整条件，以及混叠的后果
  • [ ] 我知道为什么会有"频域和时域是同一个东西的两面"这种说法

D 组 · 与控制的连接（对应 lec10/12/13）

  • [ ] 我能从传递函数直接判断闭环稳定性（不用解微分方程）
  • [ ] 我知道极点位置与响应快慢/超调的定量关系
  • [ ] 我理解反馈改变的是极点位置，而不只是"减小误差"
  • [ ] 我能说清相位裕度的物理含义（而不是只会读图）
  • [ ] 我知道状态空间的特征值与传递函数的极点是同一件事（单输入单输出时）

E 组 · 计算与直觉（这一组最容易被低估）

  • [ ] 我能估算一个 RC 电路的 fc，不用算到小数点后
  • [ ] 我看到一个传递函数能想象出它的阶跃响应大致形状
  • [ ] 我能判断一个结果是量纲上对不对
  • [ ] 我知道"τ 是到 63.2% 的时间"这个说法的来处，并能用它反推参数

⚠️ 一个重要的判断（我的推测，你可以反驳）：

大多数人"没学通"的症状落在 B 组和 C 组，而根因常在 A 组。

因为 A 组（时域与卷积）是唯一一个"动手就能验证"的层—— 你可以在纸上算卷积，也可以用数值积分验证。 而如果这一层是靠背公式过的，后面所有变换都会变成"另一套公式"， 于是这门课就分裂成了好几个互不相干的工具箱。

所以我的建议是：无论诊断结果如何，都先跑一遍 能力02_四张脸.py。 因为那个脚本用一个系统把五层串起来了 —— 而"串起来"这件事本身就是解药。

第三部分 · 12 个常见误区（按"错在哪一层"分类）

A 组 · 时域

M1 · "卷积就是那个积分公式" 错在：把卷积当运算，没当物理意义。 正确：卷积 = "把输入拆成一串冲激，每个冲激产生一个衰减的响应，全部叠加"。 检验：你能不能不用公式、用"叠加"的直觉说出方波通过 RC 后为什么变成那样？

M2 · "线性"和"时不变"混在一起 错在：以为是同一件事。 正确：线性（叠加原理）和时不变（延迟输入则延迟输出）是两个独立条件。 反例：y(t) = t·u(t) 是线性的但时变；y(t) = u(t)² 是时不变的但非线性。 为什么重要：传递函数、频率响应、卷积——全都要求 LTI。

M3 · 忽略"零输入响应"和"零状态响应"的区别 错在：解微分方程时只算了一部分。 正确：完整解 = 零输入响应（初始条件引起的）+ 零状态响应（输入引起的）。 传递函数只描述零状态响应。

B 组 · 复频域

M4 · 忽略收敛域（ROC） 错在：只算 H(s) 的表达式，不看它在哪收敛。 正确：同一个 H(s) 表达式配不同的 ROC，是不同的系统。 后果：会得出"稳定系统不稳定"或反之的错误结论。

M5 · 以为极点在左半平面"就是"稳定 错在：把它当定义背下来。 正确：那是因为极点在左半平面 → 对应的时域项是 e^(−σt) → 衰减到 0。 检验：如果极点在虚轴上呢？（临界稳定：不衰减也不发散，如纯积分器。）

M6 · 把 z = e^(sT) 当"另一个公式" 错在：没看出它是坐标变换。 正确：

s 平面               z 平面
虚轴（jω）      →    单位圆
左半平面        →    单位圆内
右半平面        →    单位圆外
``` 所以"s 左半平面稳定"和"z 单位圆内稳定"是同一句话的两个坐标写法。

## C 组 · 频域

### M7 · 混淆四种"傅里叶" 错在：把它们当同一件事。

| 名称 | 适用信号 |
|---|---|
| 傅里叶级数 | 连续、周期 |
| 傅里叶变换 | 连续、非周期 |
| DTFT | 离散、非周期（频域连续且周期） |
| DFT | 离散、有限长（频域也离散） |

口诀：时域周期 ↔ 频域离散；时域离散 ↔ 频域周期。

### M8 · 以为"频率响应"是新东西 正确：`H(jω)` 就是把 `H(s)` 里的 `s` 换成 `jω`。 而 `H(s)` 就是把微分方程里的 `d/dt` 换成 `s`。 所以频率响应 = 微分方程在正弦输入下的稳态解，不是新概念。

### M9 · 相位只是"一个角度" 错在：没理解相位的物理意义是时延。 正确：相位 −φ 在频率 ω 处等价于延迟 φ/ω。 所以相位非线性 → 不同频率延迟不同 → 波形失真（即使幅度没变）。

### M10 · 采样定理只记"两倍" 错在：只记 `fs > 2fmax`。 完整条件：① 信号带限（这本身就是个前提）；② `fs > 2fmax`； ③ 抗混叠滤波器必须在采样前（而不是采样后想办法）。 ★ 第三条最常被忽略，而现实中它才是关键。

## D 组 · 与控制连接

### M11 · 认为反馈只是"减小误差" 正确：反馈真正改变的是极点位置。 误差减小是极点移动的结果，不是原因。 这也解释了为什么反馈可能让系统不稳定——它把极点推到了右半平面。

### M12 · 把"超调"当纯粹的时域现象 正确：超调由阻尼比 ζ 决定，而 ζ 由极点的辐角决定。 所以：

超调量 ←→ 极点的辐角（与负实轴的夹角） 衰减快慢 ←→ 极点到虚轴的距离（实部绝对值） ``` 一张极点图就同时告诉了你超调和快慢。 这是控制里"看极点"的全部理由。

第四部分 · 极限检验（最实用的自学工具）

当你不确定自己算得对不对，做极限检验。 它比"重算一遍"有效得多。

检验做法该发生什么
参数极限C→0 / C→∞ / R→0 / R→∞电路退化成导线或断路
频率极限ω→0 / ω→∞电容呈开路 / 短路
时间极限t→0 / t→∞初值 / 稳态值
增益极限传递函数在 s→0 与 s→∞应是有限值且符合物理
量纲检验检查单位τ 必须是秒；ωc 必须是 rad/s
因果检验输出是否先于输入出现因果系统不该有超前
稳定性检验极点位置物理无源系统应稳定

★ 一个具体的例子（本项目 RC 电路）：

C → 0   →   τ → 0   →   fc → ∞   →   |H| ≡ 1（全通）
C → ∞   →   τ → ∞   →   fc → 0    →   |H| ≡ 0（全阻）
R → 0   →   τ → 0   →   fc → ∞   →   |H| ≡ 1（全通）

如果哪一条和你算的不一致，说明那里有错。

如果 B 组弱（复频域是空的）

1. MIT 6.003 lec03（Feedback, Poles, and Fundamental Modes）
   ↑ 这一讲从"极点"出发讲，是理解 s 域的最好入口
2. MIT 6.003 lec05（Z 变换）→ lec06（拉普拉斯变换）

   - 把 R 从 1k 改成 2k，先算 fc 会变成多少
   - 再跑，看是不是

3. 这个训练比读书有效，因为它强制你做出可被推翻的预测
