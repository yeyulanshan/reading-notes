能力 01 · 电路仿真工具迁移

从 Multisim / PSpice 迁到 LTspice

一、这个能力的定义

能做这件事，就算掌握：

拿到一个电路，能在 LTspice 里从零建好、跑出正确的分析结果、并判断结果对不对。

注意最后那个"判断对不对"是核心。 仿真最危险的地方不是"不会用"，而是算错了却以为对。

为什么这个能力值得作为第一个：

理由说明
你已经会电路所以内容不会重复你学过的，只补工具
它立刻能跑LTspice 免费，装完就能用
它消除"隔了点时间"的感觉这是你提出的核心痛点
成本最低如果"能力为产出单位"这个形态不对，改起来容易

二、为什么值得迁移（不只是"换个软件"）

Multisim 与 LTspice 的差别不是界面，是三个根本设计取向：

Multisim / PSpiceLTspice
定位教学与原理图设计一体化纯仿真引擎 + 轻量前端
网表藏在背后，你不用看第一公民，可读可改
自动化靠手动读游标.meas 把读数变成可重复的测量
依赖商业授权（学校买）免费、无水印、无限节点
在业界的地位教学常用电源/模拟 IC 工程师的日常工具

最关键的一条是 .meas。 它把"用眼睛看游标"变成"自动测量并写进日志"——这和你项目里 动手实验/ 的传统是同一件事：把观察变成可复现的测量。

三、四个例子的递进

这四个例子覆盖了 SPICE 的四类基本分析，而且每一个都对应一个你学过的概念：

例电路分析类型对应的概念
1分压（2×1kΩ）.op 直流工作点欧姆定律、分压
2RC 低通（1kΩ+1µF）.ac + .tran时间常数、截止频率、相移
3RLC 谐振（10Ω+1mH+1µF）.ac + .tran + .meas二阶系统、Q 值、超调
4方波 → RC.tran从波形反推参数（示波器工作方式）

为什么是这四个：

  • 例 1 最小，用来看懂 .op 和节点命名
  • 例 2 引入"频域/时域是两件事"——这是迁移时最容易混的地方
  • 例 3 是你（自动控制专业）最该亲手看一遍的：RLC 谐振电路的 H(s) 就是标准二阶系统，"超调量"不是抽象公式，它就是电容上的过冲电压
  • 例 4 训练的是逆向能力：只看波形反推 τ。这就是示波器上的实际工作方式

五、怎么用（学习路径）

第 0 步 · 装 LTspice

从 ADI 官网下载（免费，无需注册）：analog.com 搜 "LTspice"。 本机实测该页面可达。

注：本机没有装 LTspice（也没装 ngspice），所以下面的数值不是我"跑出来的"， 而是用 sympy 和 numpy 独立算出来的。 这两件事是等价的 —— 因为仿真器算的就是这套方程（MNA 解 KCL）。 而且独立算有个额外好处：它不受仿真器设置影响，是"真相"那一侧。

第 1 步 · 先看答案卡

cd 10_专业知识库/能力01_电路仿真工具迁移
python 能力01_电路仿真工具迁移_验证.py

它会打印四个例子的理论值。先把这个结果记住，再去跑仿真。

第 2 步 · 打开第一个网表

LTspice → File > Open → 选 网表/例1_分压电路_直流工作点.cir → Run。 然后 View > SPICE Error Log 看 .op 结果。

应该看到 V(out) = 5V。

第 3 步 · 跑完四个例子，逐个核对

例该看到什么
1V(out) = 5V，I(V1) = -5mA（负号是对的，见网表注释）
2fc = 159.2 Hz 处 −3.01 dB / −45°；高频 −20 dB/十倍频
3f0 = 5033 Hz 处有尖峰；阶跃响应超调 60.5%，之后衰减振荡
4半周期/τ = 5 时是指数形；改成 0.2 时接近三角波

第 4 步 · 自己改一个参数

这步最重要。 比如把例 2 的 R 从 1k 改成 10k，先算出 fc 会变成多少（15.92 Hz），再去跑，看是不是。

能预测改动后果 = 真的掌握了。 这和你 动手实验/ 里"改一个参数重跑"是同一个训练。

六、四类基本分析（速查）

指令名称回答什么问题何时用
.op直流工作点各节点电压/支路电流是多少每次改电路都先跑它
.dc直流扫描某个量随直流源变化看传输特性、找静态工作点
.ac小信号频域频率响应（幅度与相位）滤波器、稳定性、波特图
.tran瞬态波形随时间怎么变阶跃响应、开关、振荡

最容易混的两件事：

  • .ac 是在工作点附近线性化的，所以先要有正确的 .op。工作点错了，频率响应也不靠谱。
  • .ac 给的是"频响"，不是"波形"。 要看波形必须用 .tran。

七、这个能力怎么算"掌握"

四个自检（不用看答案能答出来）：

  • [ ] 我能说出 .op / .ac / .tran / .dc 各自回答什么问题
  • [ ] 我知道为什么 .ac 之前必须先有正确的直流工作点
  • [ ] 我能解释 I(V1) = -5mA 里的负号是什么意思（而不是把它当错误）
  • [ ] 我能在不看答案的情况下，说出改某个元件值会让 fc（或 f0）变成多少

一个综合检验：

拿一个你没见过的电路（比如你们课设里的）， 在 LTspice 里建好、跑出频响和阶跃响应、 并且能预测改一个元件值之后结果会怎么变。

八、这个能力留下的可复用经验

做完之后，值得沉淀成"下一个能力"能用的东西：

  1. 能力 XX_... 的目录结构（README + 速查表 + 故障表 + 验证脚本 + 资料）
  2. "答案卡"的做法——先用独立方法算出理论值，再去对照仿真
  3. 网表自检脚本（能力01_网表自检.py 里的 MNA 求解器可以复用到任何线性电阻网络）

本能力的理论值由 sympy / numpy 独立计算（见两个 .py 脚本），非引用、非抄录。 LTspice 网表的元件值已通过 MNA 独立求解验证，与理论一致。
