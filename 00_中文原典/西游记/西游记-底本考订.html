一 · 为什么先读这一份

这本书的引文，同样不能凭记忆写。

底本有四类形态问题：

  1. 回目格式统一，但用空格与全角空格分隔：第一回 灵根育孕源流出　心性修持大道生；
  2. 回目数字到后段变成「第九九回」「第一○○回」，不是「第九十九回」「第一百回」；
  3. 繁简混排：原底本是繁体，工作本转为简体；
  4. 旧式标点：﹔、“”、「」 混用，引用时按今读整理。

本文的立场：引文按简体工作本引；只改字形与标点，不改词句；回目按底本写法。

三 · 底本形态

3.1 回目：100 回，中文数字 + 空格

回目统一为：


第一回     灵根育孕源流出　心性修持大道生
第二回     悟彻菩提真妙理　断魔归本合元神
...
第九九回     九九数完魔灭尽　三三行满道归根
第一○○回     径回东土　五圣成真

三个要注意的地方：

  • 回目用中文数字，后段有「第九九回」「第一○○回」；
  • 回目与正文之间用空格/全角空格分隔，直接按「第X回」检索时可能带出正文里的同词；
  • 回目有两句，中间用全角空格分隔；引用回目时保留这个结构，不要合并成一句。

3.2 无缺字，但有少量 OCR 造字注记

□ 为 0；但底本仍有 3 处括号字形描述。引用时避开，或标明「底本以字形注记代替」。

不要把它们当成原文，也不要把括号里的描述猜成一个字。

3.3 繁简与异体

原底本是繁体，工作本用 Windows StrConv 整本转为简体。转换会带来：

  • 於 → 于、後 → 后、著 → 着 等常见合并；
  • 少数异体字、古字会被并到现代常用字，看不出原来的分别。

所以：

  • 引文用简体工作本，便于阅读与检索；
  • 若要做版本校勘，回原繁体底本；
  • 本文不把简体本称为「定本」，只称「工作本」。

3.4 标点

底本使用旧式标点，常见 ﹔（小分号）、“”、「」 混用。

引用时按今读统一为「；」「“”」或「」；只动标点，不动词句。

五 · 使用边界

  1. 《西游记》不是佛教教科书。它借佛道术语，但写的是小说，不是教义；不要把其中的「心性」直接当佛学定义。
  2. 不要把「八十一难」当成历史事实。它是叙事结构，不是唐代取经的真实行程。
  3. 不要用电子底本的错字做训诂。遇到可疑字，先回繁体底本，再查通行本。
  4. 引文只引工作本；如果要做学术引用，注明「据 Project Gutenberg #23962 简体工作本」，并复核繁体原文。

六 · 一句话

这本底本适合做「叙事结构」「制度隐喻」「人物关系」的分析，不适合做「佛教教义」或「唐代史」的最终依据。

引文用简体，判断回原文；两件事分开，才不会把「好读」当成「可信」。
