一 · 为什么先读这一份

这本书的引文，不能凭记忆写。

不是「记得不准」的问题，是这个底本本身有四类形态问题：

  1. 回目格式统一，但数字写法不统一：有「第一回」，也有「第一二○回」；
  2. 繁简混排：原底本是繁体，人物名、叙事文字多为繁体；
  3. OCR 造字注记：遇到生僻字，底本用「（左×右×）」「（上×下×）」描述字形，不是正文；
  4. 标点与异体字：於／后／著 等字形在繁转简后会合并，不能拿简体本做校勘。

本文的立场：引文按简体工作本引；只改字形与标点，不改词句；遇到底本注记，不把它当原文。

三 · 底本形态

3.1 回目：120 回，中文数字

回目统一为：


第一回：宴桃园豪杰三结义，斩黄巾英雄首立功
第二回：张翼德怒鞭督邮，何国舅谋诛宦竖
...
第一二○回：荐杜预老将献新谋，降孙皓三分归一统

两个要注意的地方：

  • 回目用中文数字，不是阿拉伯数字；检索「第120回」会落空；
  • 后段用「第一一三回」「第一二○回」这种写法，不是「第一百一十三回」。引用时按底本回目写，不要擅自改成另一种数字格式。

3.2 无缺字，但有 OCR 造字注记

□ 为 0，这是好消息：引文不会出现「缺字占位」。

但底本有 61 处用括号描述字形的注记，例如：

  • （左者右见）
  • （上雨下单）
  • （左马右宛）

这些不是正文，是抽取时对生僻字的替代描述。引用时要么避开，要么明确标「底本以字形注记代替」。

不要把它们当成原文的一部分，也不要把括号里的描述猜成一个字。

3.3 繁简与异体

原底本是繁体，工作本用 Windows StrConv 整本转为简体。转换会带来两类变化：

  • 於 → 于、後 → 后、著 → 着 等常见合并；
  • 少数异体字、古字会被并到现代常用字，看不出原来的分别。

所以：

  • 引文用简体工作本，便于阅读与检索；
  • 若要做版本校勘，回原繁体底本；
  • 本文不把简体本称为「定本」，只称「工作本」。

3.4 标点

底本使用旧式标点与句读，工作本保留原样，只在引用时按今读整理分句。

整理原则：只动标点，不动词句；不把「曰」改成「说」，不把「之」改成「的」。

五 · 使用边界

  1. 《三国演义》不是《三国志》。演义有大量文学加工；引用它证明「历史如何」，是把小说当史料。
  2. 「七实三虚」不是精确比例。它可以当提醒，不能当版本判据；具体人物、时间、战役要回史书。
  3. 不要用电子底本的错字做训诂。遇到可疑字，先回繁体底本，再查通行本。
  4. 引文只引工作本；如果要做学术引用，注明「据 Project Gutenberg #23950 简体工作本」，并复核繁体原文。

六 · 一句话

这本底本适合做「故事结构」和「叙事语法」的分析，不适合做「历史事实」的最终依据。

引文用简体，判断回原文；两件事分开，才不会把「好读」当成「可信」。
