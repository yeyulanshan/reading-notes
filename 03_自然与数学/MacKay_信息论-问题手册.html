A1L1总纲
这本书的 50 章其实只服务于两个对偶的问题。它们是什么？各自的"极限量"是什么？
展开参考答案
问题做什么极限在哪部分
数据压缩给定数据源，最短能用多少比特表示它熵 H(X)（下界）Part I（第 4–7 章）
噪声中的通信给定会出错的信道，多快能可靠传信息容量 C（上界）Part II–III（第 8–19 章）

关键洞察：这两件事看起来相反（压缩是去掉冗余，通信是加入冗余），但它们是同一个量的两面——因为 C 的定义本身就是互信息的最大值，而互信息由熵构成。

所以这本书可以概括成：一个量（熵），和它的两种用法。

MacKay 在第 1 章开篇引用香农 1948 年那句话来定调：

"The fundamental problem of communication is that of reproducing at one point either exactly or approximately a message selected at another point."

注意"exactly or approximately"——后半句就是"允许错误"那一半定理（R(p_b)）的伏笔。

常见误读 把这本书当"信息论入门"来读，以为它只是讲压缩和通信。它后 30 章（Part IV–VI）主要讲的是推断、机器学习、稀疏图码——MacKay 的真正立场是：推断、压缩、通信是同一件事的三个名字。
A2L1核心定义
写出 Shannon 信息量与熵的定义。它们的单位是什么？MacKay 给"信息量"起的别名是什么？
展开参考答案
定义（第 2 章，式 2.34 / 2.35）

Shannon 信息量：h(x) = log₂ (1 / P(x))

熵：H(X) = Σₓ P(x) · log₂ (1 / P(x))

熵就是信息量的平均值。单位都是比特。

那个别名

MacKay 说"信息量"的别名是 "surprise value"（意外值），而且他在第 18 章把这件事说得最清楚：

"'Information content', 'surprise value', and log likelihood or log evidence are the same thing."

——信息量 = 意外程度 = 对数似然 = 对数证据。四个名字，一个东西。

具体数字（第 2 章 table 2.9）

英语文献中随机取一个字母（27 个结果，含空格）：

字母概率信息量
z0.000710.4 bits
e0.09133.5 bits
–（空格）0.19282.4 bits

整个分布的熵约 4.11 比特。注意空格是最高频字符，所以它信息量最低——这一条很反直觉，因为空格在视觉上最"不起眼"。

两条性质

• H(X) ≥ 0，等号成立当且仅当某个 pᵢ = 1
• H(X) ≤ log₂|A_X|，等号成立当且仅当均匀分布——即"不确定性最大 = 完全不知道会是哪个"

常见误读 ① 把熵当"混乱程度"。它不是——它是不确定性，用 MacKay 的第二个名字更安全："the uncertainty of X"。
② 忘掉熵依赖于你选的分布。同一段英文，按单字母算是 4.11 比特/字母；按好的上下文模型算约 1 比特/字母（Shannon 1948）。换模型，熵就变。
A3L3证明
叙述源编码定理。为什么 MacKay 说它的结论是 "no more and no less"（不多也不少）？证明的关键工具是什么？
展开参考答案
定理陈述（第 4 章）
"N i.i.d. random variables each with entropy H(X) can be compressed into more than NH(X) bits with negligible risk of information loss, as N → ∞; conversely if they are compressed into fewer than NH(X) bits it is virtually certain that information will be lost."

形式化版本：对任意 ε > 0 与 0 < δ < 1，存在 N₀ 使得对 N > N₀，

| (1/N) · H_δ(X^N) − H | < ε

为什么是"不多也不少"

定理分两部分，而两部分的作用相反：

部分内容含义
Part 1(1/N)H_δ(X^N) < H + ε即使 δ 极小，所需比特数也从 H₀(X) 大幅降到 H + ε
Part 2(1/N)H_δ(X^N) > H − ε即使 δ 接近 1（错误成为常态），也必须至少 H − ε

MacKay 的原话：

"These two extremes tell us that regardless of our specific allowance for error, the number of bits per symbol needed to specify x is H bits; no more and no less."
证明的关键工具：典型集

路线是：大数定律 → Chebyshev 不等式 → 典型集 T_{Nβ} → 渐近等分原理 → 上下界夹逼。

典型集的定义（式 4.29）：T_{Nβ} = { x ∈ A_X^N : | (1/N)log₂(1/P(x)) − H | < β }——即"概率接近 2^(−NH) 的那些长串"。

它的三条性质：元素概率满足 2^(−N(H+β)) < P(x) < 2^(−N(H−β))；由大数定律 P(x ∈ T_{Nβ}) ≥ 1 − σ²/(β²N)；集合大小 |T_{Nβ}| < 2^(N(H+β))。

一个必须知道的细节

MacKay 明确指出：块压缩的最佳子集（按定义）是最小 δ-充分子集 S_δ，而不是典型集。那为什么还要引入典型集？

"The answer is, we can count the typical set."（因为典型集可以数得清。）

——已知它的元素概率几乎都是 2^(−NH)、且总概率几乎为 1，所以它必有约 2^(NH) 个元素。不借助典型集，根本数不清 S_δ 有多少元素。

常见误读 ① 把定理当成"我应该能得到 NH 比特"——它证明的是存在性，不是构造方法。（第 4 章没有给出实用算法；第 5、6 章才补上符号码与流码。）
② 忘掉前提：分布已知 + 独立同分布 + 块长可任意大。分布未知时下界不再可达——这正是 Lempel–Ziv 存在的原因（通用，但只在数据量不可行地大时才兑现）。

香农之前的共识：没有付出就没有收获

MacKay 把当时的普遍信念描述成一个曲线形状的猜想：可达到与不可达到的分界是一条穿过原点的曲线。

也就是说：要让错误率趋近于零，速率就必须相应地趋近于零。——"No pain, no gain."

香农证明的：分界线在 R 轴上交于非零点

那个非零交点就是信道容量 C。定理的完整陈述（第 10 章）：

部分内容
正面一对任意 DMC，C = max_{P_X} I(X;Y)。对任意 ε > 0、R < C，只要 N 足够大，就存在长度 N、速率 ≥ R 的码和译码算法，使最大块错误概率 < ε
正面二若允许比特错误率 p_b，速率可达 R(p_b) = C / (1 − H₂(p_b))
负面任何大于 R(p_b) 的速率都不可达

MacKay 在小结里把两面并列，这一点很重要：它既是悲观的上界，也是乐观的下界。很多人只记住"不可能"那一半。

"The noisy-channel coding theorem ... asserts both that reliable communication at any rate beyond the capacity is impossible, and that reliable communication at all rates up to capacity is possible."
二进制对称信道

容量公式（式 1.35 / 9.11）：C(f) = 1 − H₂(f)，其中 H₂ 是二进制熵函数。

f = 0.1 时：C = 1 − H₂(0.1) ≈ 0.53。

其他模型信道的容量（第 9 章）：BEC C = 1 − f = 0.85（f = 0.15）；Z 信道 C = 0.685；噪声打字机 C = log₂ 9 比特。

他讲这个的方式极好：磁盘比喻

设 f = 0.1：

方法达到的错误率需要几个噪声盘
重复码 R3p_b = 0.033 个
重复码 R60p_b ≈ 10⁻¹⁵60 个
香农极限任意小，10⁻¹⁸、10⁻²⁴ 都行2 个（因为 1/2 < 0.53）

然后他写了那段著名的香农"路过"的对话："你要 10⁻¹⁵？你不需要六十个盘——两个盘就够了。"

而他立刻自己踩了刹车（这是全书诚实性的样板）

他加了一个方括号说明：严格说来上面的话可能不完全对，因为香农是靠块长不断增大的块码序列证明定理的，而所需块长可能比一个 GB 还大。那时香农大概会说："好吧，那些小盘做不到，但如果你有两个噪声 TB 盘，你就能造一个高质量 TB 盘。"

常见误读 ① 把"任意小错误"的 C 与"允许错误"的 R(p_b) 混为一谈。前者是"近乎无误"的界限；后者是"有损传输"的界限，且 R(p_b) > C（p_b > 0 时）。所以"R ≤ C"这条常见口号只对第一部分成立。
② 把 R(p_b) = C/(1−H₂(p_b)) 与 BSC 的 C = 1 − H₂(f) 搞混——两个公式形式相似，含义毫不相干：前者的 p_b 是你容忍的译码错误率，后者的 f 是信道噪声。
③ 把容量当工程承诺。它是渐近结果——只保证"存在这样的码"，不保证"这个码多长、多难解码"。

B1L4辨误
有人说"熵就是混乱程度""信息越多越好"。用这本书的定义说明这两个说法错在哪。请给出一个可以立刻识别的检验方法。
展开参考答案
"熵 = 混乱程度" 错在哪

熵的准确含义是不确定性，操作性地说是"平均每个结果需要多少比特来描述"。

两个反例：

① 熵与"看得见的乱"无关。一串完全随机的比特熵最大——但它一点也不"乱"得有意义，它只是没有结构。反过来，一篇高度结构化的文本熵较低。

② 熵是相对于模型的。同一段英文，按单字母分布算 4.11 比特/字母，按好的上下文模型算约 1 比特/字母。换模型，熵就变——所以熵不是事物的属性，是你对该事物的模型的属性。

"信息越多越好" 错在哪

信息量的定义是 h(x) = log₂(1/P(x))：概率越小，信息量越大。

所以"信息"在这里的意思是意外程度，与"有用""有意义""是知识"都无关。一串完全随机的字符信息量最大化，但它什么也没告诉你。

MacKay 给了一个极好的演示（第 4 章，潜艇游戏）：

事件信息量
潜艇藏在 64 格中，第一发就打中log₂ 64 = 6 bits
第一发未中log₂(64/63) ≈ 0.0227 bits

一次二元结果可以携带 6 比特的信息——因为信息量取决于结果有多不可几，不取决于用了几个二元符号。

两个立刻可用的检验

检验一：把"熵"换成"平均需要多少比特"再读一遍。如果句子变得荒谬（"这个房间的平均比特数在增加"），原句也是荒谬的。

检验二：把"信息"换成"意外程度"再读一遍。不通，则不是这本书的"信息"。

再加一个：问"这件事的概率是多少？"——如果这个"信息量"无法对应到任何概率，它就不是 Shannon 意义上的信息量。

常见误读 还有一个连带的误读值得记："bit"这个词在书里有两个含义（MacKay 在定义处就主动提醒了）：① 一个取两个值的符号；② 信息量的单位。混起来就会得出"一个 bit 只能携带一个 bit 的信息"这种循环而无用的结论——它恰好掩盖了上面潜艇游戏那个反例。
B2L3核心概念
"渐近等分"（asymptotic equipartition）这个词里的"等分"是什么意思？MacKay 为什么专门给这个词加了引号？
展开参考答案
典型集是什么

典型集 T_{Nβ} 的元素，其 log₂(1/P(x)) 彼此相差在 2Nβ 之内；集合约有 2^(NH) 个成员，总概率接近 1。

为什么加引号

MacKay 的原话：

"I put the words 'asymptotic equipartition' in quotes because it is important not to think that the elements of the typical set really do have roughly the same probability as each other... As β decreases, N increases, and this ratio grows exponentially. Thus we have 'equipartition' only in a weak sense!"

关键句是后半段：典型集里最可能的串与最不可能的串之比可以达到 2^(α√N)，这个比值随 N 指数增长。

所以"等分"只在很弱的意义上成立——正确的说法是"它们的对数概率彼此接近"，而对数接近不代表概率接近，因为指数放大了差异。

还容易混的一点

典型集 ≠ 最小 δ-充分子集 S_δ。

典型集反而不包含那些最高概率的串（MacKay 说它们的总概率贡献可忽略）；而 S_δ 恰恰从最高概率的元素开始收集。

举例（例 4.6）：8 个结果、概率 {1/4, 1/4, 1/4, 3/16, 1/64, 1/64, 1/64, 1/64}。前四个的总概率是 15/16，所以容许 δ = 1/16 时只需 4 个名字 = 2 比特——这就是 S_δ 的做法，它抓的是最高概率的那几个，而不是"概率接近 2^(−NH)"的那些。

还要区分三个 H
记号名称含概率吗
H₀(X)原始比特含量 log₂|A_X|，只数结果个数没有
H_δ(X)本质比特含量 log₂|S_δ|，容许概率 δ 的丢失有，依赖 δ
H₂(p)二元熵函数 H(p, 1−p)有
常见误读 MacKay 把"不要混淆 H₀、H_δ 与 H₂"写成了一条正式警告（他的原话就有 "Caution: do not confuse..."）。这三个记号形式上都像"比特数"，但含义完全不同。
B3L3核心概念
什么是 KL 散度？它的操作性解读是什么？MacKay 对它的评价有多高？它的一个常被忽略的性质是什么？
展开参考答案
定义（第 2 章，式 2.45）

D_KL(P‖Q) = Σₓ P(x) · log( P(x) / Q(x) )

满足 Gibbs 不等式：D_KL(P‖Q) ≥ 0，等号当且仅当 P = Q。

操作性解读

它是"用为 Q 优化的编码去编 P 的数据，平均要多付多少比特"。

这一点有一个很干净的恒等式（式 5.23）：若真实分布是 p，而用的完备码隐含分布是 qᵢ = 2^(−lᵢ)，则

L(C, X) = H(X) + D_KL(p‖q)

——超出熵的部分恰好就是相对熵。

MacKay 的评价
"Gibbs' inequality is probably the most important inequality in this book."

（这大概是本书最重要的不等式。）而它的证明工具是 Jensen 不等式：对凸函数 f，E[f(x)] ≥ f(E[x])。

MacKay 还给了个很好记的读法：凸函数念"convex-smile"（⌣），凹函数念"concave-frown"（⌢）——"虽然你可能忘记 convex 和 concave 朝哪边，但把微笑和皱眉搞混要难得多。"

那个常被忽略的性质：不对称

✎ 作者已澄清——一般 D_KL(P‖Q) ≠ D_KL(Q‖P)。所以虽然有人叫它"KL distance"，它严格来说不是距离（距离要求对称，还要求三角不等式）。

还有一条更深的用途

互信息就是 KL 散度（式 8.11）：

I(X;Y) = D_KL( P(x,y) ‖ P(x)P(y) )

——所以"互信息非负"这件事直接来自 Gibbs 不等式。这个形式还很直观：它度量的是"联合分布与独立分布有多远"。

常见误读 把 KL 当距离用来做聚类或算"两个分布的远近"而不注意方向。检验方法：问"你算的是 D(P‖Q) 还是 D(Q‖P)？你为什么要这个方向？"——能答出理由的（如"我要用 Q 去编码 P 的数据"）是正确用法。

模块 C · 香农证明的艺术：不去构造，去平均

定理的证明方法本身比结论更值得学。
C1L3证明思路
香农怎么证明"好码存在"？请说明随机编码的思路，以及那个著名的"称婴儿"类比。
展开参考答案
思路的转折

香农的革新在于不去构造一个好码再评估它的错误率，而是：

"instead of constructing a good coding and decoding system and evaluating its error probability, Shannon calculated the average probability of block error of all codes, and proved that this average is small. There must then exist individual codes that have small probability of block error."

——对所有随机生成的码求平均，证明平均值小，从而推出"必然存在个别好码"。

"称婴儿"的类比（原话）
"Shannon's method of solving the task is to scoop up all the babies and weigh them all at once on a big weighing machine. If we find that their average weight is smaller than 10 kg, there must exist at least one baby who weighs less than 10 kg – indeed there must be many!"
证明的三块砖
  1. 随机编码：固定输入分布 P(x)，按它随机生成 S = 2^(NR') 个码字，构成一个码 C。编解码双方都知道 C。
  2. 典型集译码：若 (x(ŝ), y) 联合典型、且没有别的码字与 y 联合典型，则译成 ŝ；否则宣告失败。MacKay 明说这个译码器"不是最优的，但够用而且更好分析"。
  3. 三种错误概率：单个码的 p_B(C)（难算）；对所有码的平均 ⟨p_B⟩（好算，这就是要证的量）；最大错误概率 p_BM(C)。由码构造的对称性，⟨p_B⟩ 与所选消息 s 无关。
误差只有两个来源
来源概率
(a) 输出的 y 与所发码字不联合典型记为 δ，随 N → ∞ 趋零
(b) 有别的码字与 y 联合典型每个候选 ≤ 2^(−N(I(X;Y)−3β))，而候选有 2^(NR')−1 个

用 union bound：

⟨p_B⟩ ≤ δ + (2^(NR')−1) · 2^(−N(I(X;Y)−3β)) ≤ δ + 2^(−N(I(X;Y)−R'−3β))

只要 R' < I(X;Y) − 3β，增大 N 即可使 ⟨p_B⟩ < 2δ。

最后一步极妙：expurgation（剔除）

平均值小 ⟹ 存在一个码其错误率小于 2δ。但要证明的是最大块错误概率小，不是平均。

办法是扔掉最差的一半码字：剩下码字的条件错误概率 < 4δ，码字数从 2^(NR') 降到 2^(NR'−1)——即速率从 R' 降到 R' − 1/N（N 大时可忽略）。于是得到 p_BM < 4δ。

union bound 的准确定义（MacKay 特意交代）
"...bounds a total probability of error by the sum of the probabilities of all sorts of events each of which is sufficient to cause error is called a union bound. It is only an equality if the different events that cause error never occur at the same time as each other."
常见误读 ① 以为这个证明给出了一个可用的编码方案。它完全是存在性证明——而且 MacKay 自己指出：随机码虽然好，但"需要指数规模的资源来编译码"，而一般的最大似然译码问题是 NP-complete 的。
② 漏掉 expurgation 这一步。没有它，证明只给出"平均好"，而不是定理要求的"最大错误概率小"。

"几乎所有码都是好码"的完整含义

MacKay 的原话有两半，第二半常被忽略：

"Nearly all codes are good, but nearly all codes require exponential look-up tables for practical implementation of the encoder and decoder – exponential in the blocklength N. And the coding theorem required N to be large."

所以"好码存在"不等于"我们知道怎么写出来"，更不等于"能多项式时间译码"。他还补了一句实践总结：

"Random codes are good, but they require exponential resources to encode and decode them. Non-random codes tend for the most part not to be as good as random codes."
真正刻画有限块长行为的是两个指数

单独的 C 只说渐近行为。有限 N 下的行为由这两个量决定：

量含义界
随机编码指数 E_r(R)（又称可靠度函数）存在性一侧，0 ≤ R < C 上凸、递减、正值，R → C 时趋于 0p_B ≤ exp[−N · E_r(R)]
球填充指数 E_sp(R)下界一侧，刻画任何块长 N 的码能做到的最好水平p_B ≥ exp[−N · E_sp(R)]

MacKay 特别指出：即使对 BSC 这样简单的信道，E_r(R) 也没有简单表达式。

"顾客"那个比喻

他设想了这样一个场景：一位顾客想买一套纠错码与译码器。香农定理告诉他"存在"，但——

"Unfortunately we have not found out how to implement these encoders and decoders in practice; the cost of implementing the encoder and decoder for a random code with large N would be exponentially large in N."
然后是整本书最实用的一句话

第 11 章小结给出了实用好码的三个共同特征：

  1. 采用很大的块长
  2. 建立在半随机的码构造之上
  3. 使用基于概率的译码算法（消息传递）

这就是 Turbo 码（1993）与 LDPC 码（Gallager 1962，1995 年重新发现）的位置——Part VI 讲的 LDPC、Repeat-Accumulate、数字喷泉码，就是来填"存在性"与"可构造性"之间这道鸿沟的。

还有一个必须知道的复杂度事实

一般的最大似然译码问题是 NP-complete 的（Berlekamp et al. 1978）。即求 G^T s + n = r 中最大似然的 s。

常见误读 "几乎所有的码都是好码，所以随便挑一个码就行。"——漏掉了两件事：好码几乎都需要指数规模的查表；而且定理要求 N 很大，这与工程上的延迟、成本约束直接冲突。

第 3 章。如果只读一章，读这一章。
D1L3核心示范
MacKay 讲了 Steve Gull 给他上的一课。问题的症结是什么？Gull 做了什么？请描述那个"峰出现"的瞬间。
展开参考答案
问题（一个 Tripos 考题）

不稳定粒子以特征长度 λ 做指数衰减，但只能在 x = 1cm 到 20cm 的窗口里观测到 N 个衰变位置。问 λ 是多少？

症结：标准工具全都失效

MacKay 试了两条路，都卡住了：

① 构造估计量。因为无约束指数分布的均值就是 λ，看起来 λ̂ = x̄⁻¹ 对 λ ≪ 20cm 合适——但当右侧截断显著时就不行了。他用"一点聪明加上一些 ad hoc 的分箱"能造出 λ ≫ 20cm 的估计量，但"没有任何一个估计量在所有情况下都管用"。

② 拟合直方图。也不满意。

他的困境正是标准统计学的困境："是不是每次遇到新的推断问题，都得在黑暗中摸索合适的'估计量'，还得操心哪个估计量是'最好'的（不管那是什么意思）？"

Gull 做的三件事
  1. 写出给定 λ 时一个数据点的概率 P(x | λ)（含归一化因子 Z(λ)，因为有 1–20 的截断）——这很平常
  2. 写出 Bayes 定理
  3. 然后把同一个函数反过来，看成 λ 的函数
"峰出现"的瞬间（原话）
"A simple figure showed the probability of a single data point P(x|λ) as a familiar function of x, for different values of λ. Each curve was an innocent exponential, normalized to have area 1. Plotting the same function as a function of λ for a fixed value of x, something remarkable happens: a peak emerges."

——每条曲线本来都是"一条无辜的指数曲线"；但当你固定 x、把它画成 λ 的函数时，一个峰出现了。

Gull 对定理的总结（全书最好的一句概括）
"what you know about λ after the data arrive is what you knew before [P(λ)], and what the data told you [P({x}|λ)]."

（数据到来之后你知道的 = 你之前知道的 + 数据告诉你的。）

MacKay 由此得出的强硬结论

后验分布"就是这个问题的唯一且完整的解"——不需要发明"估计量"，也不需要发明比较不同估计量的标准。

"While orthodox statisticians offer twenty ways of solving a problem, and another twenty different criteria for deciding which of these solutions is the best, Bayesian statistics only offers one answer to a well-posed problem."
一个必须澄清的误解（MacKay 主动交代）

他明确说：λ 不是一个随机变量。用概率分布 P(λ) 不代表他认为世界在不同假设之间随机变来变去——他只是在用概率记号表达信念（degrees of belief），而这些备选假设中只有一个是真的。

常见误读 把这一课读成"贝叶斯方法就是加个先验"。真正的要点是视角的翻转：P(x|λ) 与 P(λ|x) 是同一个函数的两种看法，前者是"给定模型看数据"，后者是"给定数据看模型"。这个翻转就是整个推断理论。
D2L3核心论证
叙述那个血型证据的例子。为什么"现场有 O 型血"不是支持 O 型嫌疑人到场的证据？请写出一般的似然比公式。
展开参考答案
案情

犯罪现场留下两个人的血：一为 O 型（当地频率 60%），一为 AB 型（频率 1%）。嫌疑人 Oliver 是 O 型。这些数据支持"Oliver 在场"吗？

粗心律师会说"现场有 O 型血，所以支持"。MacKay 说：不成立。

计算

设 S = "Oliver 与一个未知的人在场"，S̄ = "两个未知的人在场"，D = 观测到的数据。

P(D | S) = p_AB（已知 S 时，另一个未知的人必须是 AB 型）

P(D | S̄) = 2 · p_O · p_AB（两个未知的人，一个是 O 一个是 AB，有 2 种顺序）

于是似然比：

P(D|S) / P(D|S̄) = 1 / (2 p_O) = 1/(2×0.6) ≈ 0.83

小于 1——这些数据其实是反对 Oliver 在场的弱证据。

但如果嫌疑人是 AB 型（假想人物 Alberto），似然比变成 1/(2p_AB) = 50——强证据。

一般公式（第 3 章，式 3.30）

设现场共 N 处血迹，其中 n_O 处为 O 型、n_AB 处为 AB 型：

似然比 = (n_O / N) ÷ p_O

MacKay 的解读：

"The likelihood ratio ... depends simply on a comparison of the frequency of his blood type in the observed data with the background frequency in the population. There is no dependence on the counts of the other types found at the scene, or their frequencies in the population."
两个直觉说明（MacKay 给的）

说明一（逻辑上的）：如果现场有 O 型血就支持"每一个 O 型的人都在场"，那所有人都会变得更可疑——这显然荒谬。所以他总结："如果数据支持某些假设，它们必然也反对另一些假设。"

说明二（换成数字的）：设想现场有 10 处血迹，当地 100 个嫌疑人中 90 个是 O 型、10 个是 AB 型。Oliver 是某个 O 型嫌疑人。

时点Oliver 在场的概率
血检之前（已知 10 人曾到场）1/10
血检之后：10 处血迹中 9 处 AB、1 处 O1/90

证据让他的嫌疑下降了——因为现场只有一个 O 型的人。

一个制度性的观察（很值得记）

MacKay 认为陪审团的任务应该是把每项独立证据的似然比与审慎推理出的先验概率相乘。但他补了一句："这一观点得到许多统计学家的认同，但博学的英国上诉法官最近不同意，并且实际上因为陪审员被教导用 Bayes 定理处理复杂的 DNA 证据而推翻了一次判决。"

常见误读 把"数据与假设相容"当成"数据支持假设"。这两件事完全不同：O 型血与"Oliver 在场"完全相容，但它不提供支持。决定支持与否的是该特征在现场的频率 vs 它在人群中的频率。这条逻辑直接推广到 DNA 证据、基率谬误、以及一切"命中率很高所以有罪"式的论证。
D3L4核心立场
MacKay 反复说"你不能不做假设"。请给出他在书里说过的三种措辞，以及他为这个立场给出的两条理由。
展开参考答案
三种措辞（针对不同靶子）
场合原话
推断（第 3 章）"you cannot do inference without making assumptions."
压缩（第 3 章）"you can't do inference – or data compression – without making assumptions."
反问（第 3 章）"How can one perform inference without making assumptions?"

注意第二句把压缩也拉进来了——这不是随口一提。压缩需要假设一个概率模型，而模型就是假设。所以他的立场是：推断与压缩是同一件事的两面，因而共享同一个前提。

两条理由（原话）

理由一：假设一旦明说，推断就是客观且唯一的。

"once assumptions are made, the inferences are objective and unique, reproducible with complete agreement by anyone who has the same information and makes the same assumptions."

理由二：假设一旦明说，就更容易被批评和修改。

"when the assumptions are explicit, they are easier to criticize, and easier to modify – indeed, we can quantify the sensitivity of our inferences to the details of the assumptions."
他对"先验从哪来"这个经典质疑的回应

"I don't see how it could be otherwise. How can one perform inference without making assumptions? I believe that it is of great value that Bayesian methods force one to make these tacit assumptions explicit."

（我看不出还能怎么样……我认为贝叶斯方法迫使你把这些隐含假设说出来，这是极大的价值。）

他也不为随便挑先验开脱

他明确说："我不会声称均匀先验有任何根本性"（"I will not claim that the uniform prior is in any way fundamental"），而且后面专门给出非均匀先验的例子。先验是主观假设——他承认这一点，然后说既然如此就把它写出来。

他还警告读者一件事

（读者要被告知，这还不是全球共识——统计学的领域在 20 世纪大部分时间里由非贝叶斯方法主导。）他自己是贝叶斯派，而且他知道这一点，所以主动标注了。

模块 E · 模型比较：奥卡姆剃刀不是原则

第 3 章埋线，第 28 章展开。这是全书方法论的顶点。
E1L3核心概念
什么是证据（evidence）？MacKay 给了一个极实用的操作提示：证据在贝叶斯推断里通常是什么东西？
展开参考答案
定义

证据是两个模型比较时的数据依赖项：P(s | F, H₁)——"给定模型 H₁，观测到这组数据的概率"。

后验几率的分解（式 3.21）：

P(H₁|s,F) / P(H₀|s,F) = [ P(s|F,H₁) · P(H₁) ] / [ P(s|F,H₀) · P(H₀) ]

即：后验几率 = 先验几率 × 证据比。

那个极实用的操作提示
"The evidence for a model is usually the normalizing constant of an earlier Bayesian inference."

（一个模型的证据，通常是先前某次贝叶斯推断的归一化常数。）

这句话的意思是：你已经算过一次的东西可以复用。当你对参数做推断时，那个被除掉的归一化常数看起来只是个讨厌的常数；但当你要比较模型时，它就是证据。

积分形式（第 28 章，式 28.7）

P(D|H_i) = ∫ P(D|w, H_i) · P(w|H_i) dw

即似然对先验的积分。这就是为什么做模型比较时必须用正常（proper）先验——先验不可归一化，这个积分就没有意义。

弯硬币的例子（第 3 章）

H₀：正六面骰子，p = 1/6（零个自由参数）。H₁：弯硬币，p 可取 0 到 1 任意值（一个自由参数）。

MacKay 用这个对比给出了一张表（table 3.5），其中几个数值很值得看：

F数据 (Fa, Fb)P(H₁|s,F)/P(H₀|s,F)
6(5, 1)222.2
6(1, 5)0.356 = 1/2.8
20(10, 10)96.5
20(3, 17)0.2 = 1/5

注意 (1,5) 那一行——这组数据看起来最符合 H₀（骰子的期望比例正是 1:5），但证据比却是 1/2.8 反对 H₀。这就是奥卡姆因子在起作用。

常见误读 把证据当成"模型拟合数据的好坏"。它是似然对先验的积分——一个模型可以拟合得很好，但因为"能拟合的东西太多"，它的证据反而低。见下一题。
E2L4本书顶点
请说明：为什么奥卡姆剃刀不是一条需要额外施加的原则？写出 Occam 因子并解释它的几何意义。为什么"数参数个数"不是好的复杂度度量？
展开参考答案
MacKay 要立的命题
"However there is a different justification for Occam's razor, namely: Coherent inference (as embodied by Bayesian probability) automatically embodies Occam's razor, quantitatively."

他还列出另外两种常见的"理由"：审美理由（Dirac：数学上美的理论更可能正确）和历史经验理由（过去管用）。他要立的是第三种。

机制不在"参数少"，而在预测的弥散程度
"But such a prior bias is not necessary: the data-dependent factor embodies Occam's razor automatically. Simple models tend to make precise predictions. Complex models, by their nature, are capable of making a greater variety of predictions. So if H₂ is a more complex model, it must spread its predictive probability P(D|H₂) more thinly over the data space than H₁."

而先验只需要等概率就够：

"Our subjective prior just needs to assign equal prior probabilities to the possibilities of simplicity and complexity. Probability theory then allows the observed data to express their opinion."
Occam 因子的推导

证据是似然对先验的积分：P(D|H_i) = ∫ P(D|w,H_i)P(w|H_i)dw。

由于后验在峰值 w_MP 处有强峰，积分近似为"峰高 × 峰宽"：

P(D|H_i) ≃ P(D|w_MP, H_i) × P(w_MP|H_i) × σ_{w|D}

而 MacKay 用文字给出的分解式更清楚：

证据 ≃ 最佳拟合似然 × Occam 因子

若先验在宽度 σ_w 上均匀，则 P(w_MP|H_i) = 1/σ_w，于是

Occam 因子 = σ_{w|D} / σ_w

几何意义（原话）
"i.e., the Occam factor is equal to the ratio of the posterior accessible volume of H_i's parameter space to the prior accessible volume, or the factor by which H_i's hypothesis space collapses when the data arrive. The model H_i can be viewed as consisting of a certain number of exclusive submodels, of which only one survives when the data arrive. The Occam factor is the inverse of that number. The logarithm of the Occam factor is a measure of the amount of information we gain about the model's parameters when the data arrive."

所以 Occam 因子就是"数据到来时假设空间坍缩的倍数"，而它的对数等于我们从数据中获得的关于该模型参数的信息量（这正好回到模块 A 的信息量定义）。

为什么"数参数个数"不是好度量

MacKay 明确写了这一条，而且它很反直觉：

"The Occam factor also penalizes models that have to be finely tuned to fit the data, favouring models for which the required precision of the parameters σ_{w|D} is coarse. The magnitude of the Occam factor is thus a measure of complexity of the model; it relates to the complexity of the predictions that the model makes in data space. This depends not only on the number of parameters in the model, but also on the prior probability that the model assigns to them."

也就是说：一个参数很多但先验范围极窄的模型，可能比一个参数很少但先验范围极宽的模型受到更轻的惩罚。

——这一条直接否掉了"数参数个数"式的复杂度度量（如 AIC/BIC 那类做法对复杂度的理解）。

"巧合让我们起疑"是定量的

箱子谜题（第 28 章）：50 像素区域、树干 10 像素、16 种颜色、高/宽/位置各约 20 个可分辨值。比较"一个箱子"与"两个箱子"：

P(D|H₁)/P(D|H₂) = 20 × 2 × 2 × 16 ≃ 1000 / 1

支持更简单的假设约 1000:1。MacKay 的解读：

"It has to pay two big Occam factors (1/20 and 1/16) for the highly suspicious coincidences that the two box heights match exactly and the two colours match exactly."

——这就是"可疑的巧合"的价格。

一个重要的计算成本结论
"In summary, Bayesian model comparison is a simple extension of maximum likelihood model selection: the evidence is obtained by multiplying the best-fit likelihood by the Occam factor. To evaluate the Occam factor we need only the Hessian A... Thus the Bayesian method of model comparison by evaluating the evidence is no more computationally demanding than the task of finding for each model the best-fit parameters and their error bars."

（只多一个 Hessian，而算误差棒本来就要它。）

常见误读 ① 把奥卡姆剃刀当成需要手动加的惩罚项（如正则化）或审美偏好。它自动从概率论里出来，而且先验只需等概率。
② 把它读成"参数少就好"。惩罚的是需要被精细调校（σ_{w|D} 小），不是参数个数。
③ 把它当成"必须挑一个模型"。见 E3。
E3L4辨误
"模型比较"与"模型选择"是同一件事吗？MacKay 怎么说的？另外，他指出了一个关于贝叶斯的"流行神话"，那是什么？
展开参考答案
不是同一件事（原话）
"When we discuss model comparison, this should not be construed as implying model choice. Ideal Bayesian predictions do not involve choice between models; rather, predictions are made by summing over all the alternative models, weighted by their probabilities."

（当我们讨论模型比较时，不应把它理解为暗示模型选择。理想的贝叶斯预测不涉及在模型之间做选择；预测是通过对所有备选模型按其概率加权求和得到的。）

他还说明了为什么："本章只涉及推断，不涉及损失函数。"——比较模型是推断，决定行动是决策论，两件事分开。

那个"流行神话"
"There is a popular myth that states that Bayesian methods differ from orthodox statistical methods only by the inclusion of subjective priors... It is true that, at the first level of inference, a Bayesian's results will often differ little from the outcome of an orthodox attack. What is not widely appreciated is how a Bayesian performs the second level of inference; this chapter will therefore focus on Bayesian model comparison."

（有一个流行的神话：贝叶斯方法与正统统计方法的区别只在于多了个主观先验……确实，在第一层推断上，贝叶斯的结果往往与正统做法差别不大。而不被广泛理解的是贝叶斯如何做第二层推断。）

——“第一层”是在给定模型内拟合参数；“第二层”是模型比较。真正有区别的是第二层。

顺带一个必须记住的前提
"If we want to do model comparison, it is essential to use proper priors – otherwise the evidences and the Occam factors are meaningless."

而他的实践忠告是："always use proper priors, tempered by an encouragement to be smart when making calculations, recognizing opportunities for approximation."（总是用正常先验；但同时要聪明地计算，识别可以近似的地方。）

为什么这一条容易踩坑

非正常先验（如平坦先验、1/σ 先验）在第一层（边缘化 nuisance 参数）里用得很舒服、常常无害。但在第二层它们会让证据和 Occam 因子失去意义。所以必须严格区分两种目的。

MDL 的互补视角

MacKay 还把这一整套翻译成了比特语言：P(x) = 2^(−L(x))，两部分消息 L(D,H) = L(H) + L(D|H)。他指出一个微妙点：参数的发送精度存在非平凡的最优值（精度放低则参数消息短、数据消息长）——而"最优参数消息长度与 Occam 因子的对数几乎完全相同"。

他对 MDL 的评价很克制："MDL has no apparent advantages over the direct probabilistic approach"，但"MDL does have its uses as a pedagogical tool"。

常见误读 算出证据比之后直接把低分模型丢掉、只用最好的那个做预测。这等于假装其他模型的概率为零，而证据比通常不支持这么强的结论。
另一个连带误读：以为"贝叶斯 = 多了个先验"。这样理解就漏掉了第二层，而第二层才是真正有区别的地方。

模块 F · 推断的三个陷阱

第 22 章。三个方法都比它们看起来更糟，而它们在实践中被大量使用。
F1L4辨误
最大似然有什么致命缺陷？MacKay 用了一个拟声词来描述它，那是什么？请说出他对"为什么我们不该在意这个巨大的似然"的诊断。
展开参考答案
那个拟声词
"KABOOM! ... Put one cluster exactly on one data point and let its variance go to zero – you can obtain an arbitrarily large likelihood!"

（把一个簇正好放在一个数据点上，让它的方差趋于零——你就能得到任意大的似然！）

这就是过拟合：ML 会找到"高度调优、完美拟合部分数据"的模型。

他的诊断（很精确）
"The reason we are not interested in these solutions with enormous likelihood is this: sure, these parameter-settings may have enormous posterior probability density, but the density is large over only a very small volume of parameter space. So the probability mass associated with these likelihood spikes is usually tiny."

——密度大 ≠ 质量大。尖峰很高，但底面积趋零，所以总质量微不足道。

即使没有无穷尖峰，问题依然存在
"Even if the likelihood does not have infinitely-large spikes, the maximum of the likelihood is often unrepresentative, in high-dimensional problems. ... Maxima are atypical."

（最大值不是典型值。）——这是一个通用的高维事实：概率质量集中在典型集，而典型集与密度最大点性质完全不同。

为什么它是模型选择上的灾难

第 28 章说得最直接：

"Model comparison is a difficult task because it is not possible simply to choose the model that fits the data best: more complex models can always fit the data better, so the maximum likelihood model choice would lead us inevitably to implausible, over-parameterized models, which generalize poorly. Occam's razor is needed."
正确的替代是证据

证据 = 最佳拟合似然 × Occam 因子。——ML 只是其中一个因子，被 Occam 因子折价。

一个很好的症状（习题 22.8，光子计数）

带背景 b 时 ML 给出 λ̂ = max(0, r − b)，而抽样理论的"无偏估计量"给出 r − b = −4——一个负的光子率。

常见误读 用似然（或等价地，训练误差）来比较不同复杂度的模型。这是实践中最常见的一类误用，而且它的症状很隐蔽——因为"拟合得更好"本身看起来就是好事。
F2L4辨误
MAP（最大后验）能补救最大似然吗？MacKay 列出了 MAP 的三宗罪，请说明。请用那个"空洞数据"的例子说明第三条。
展开参考答案
三宗罪
问题说明
① 尖峰未必被压住后验密度也常有无限尖峰；乘个先验不等于解决
② 最大值不代表性高维下概率质量集中在典型集——"Maxima are atypical"
③ 依赖基P(u) = P(θ)|∂θ/∂u|；非线性换基后最大值位置通常改变
第三条他讲得最重
"A further reason for disliking the maximum a posteriori is that it is basis-dependent. ... It seems undesirable to use a method whose answers change when we change representation."

（用一个换表示法答案就变的方法，看起来不可取。）

"空洞数据"的例子（习题 22.16）——极具说服力

Scenario 1：数据 {2.2, −2.2, 2.8, −2.8}，测量噪声 σ = 1。MAP 给出 w_MP = {1.8, −1.8, 2.2, −2.2}（误差棒 ±0.9）——合理的。

Scenario 2：加入四个用 σ' = 100 测的"空洞"数据 {100, −100, 100, −100}。这些数据几乎不含信息（噪声极大）。

结果：MAP 把原本良测的参数从 1.8/2.2 拖到 0.03/0.04。

——毫无信息的测量摧毁了有效推断。
正确做法

把 nuisance 参数边缘化掉（积分掉），而不是与它们一起取最大。

MacKay 在说到贝叶斯推断时给了对照："in Bayesian inference ... once we have made explicit all our assumptions about the model and the data, our inferences are mechanical."（一旦假设写明，推断就是机械的。）——他还指出抽样理论的估计量常常作为后验的众数或均值自动浮现。

常见误读 以为"ML 有毛病，那乘个先验取最大就好了"。MacKay 对 MAP 的批评比对比 ML 的更具体——三条中的任何一条都足以否定它作为通用方法。特别要注意第三条：它是方法论层面的反对（答案不该随表示法改变），不是数值层面的。
F3L4辨误
"变分方法就是找一个近似分布，近似得越准越好"——这句话哪里不对？请用二维高斯那个练习的两种答案来说明。
展开参考答案
核心是 KL 的方向性

变分目标是最小化 βF̃(θ) = D_KL(Q‖P) + βF。而这个方向会惩罚"P 大而 Q 小"的地方（因为它含 Q log(Q/P)，当 Q 小而 P 大时惩罚极重）。

结果：近似分布会挤进 P 的某一个峰，系统性偏窄。MacKay 把它写成一条准则：

"The approximations given by variational free energy minimization always tend to be more compact than the true distribution."
两个数值答案（习题 33.5）

用球形高斯去近似一个各向异性高斯（标准差 σ₁ = 10、σ₂ = 1）：

目标结果数值
最小化变分自由能（D_KL(Q‖P) 方向）1/σ_Q² = ½(1/σ₁² + 1/σ₂²)（逆方差平均）σ_Q ≈ √2
最小化 G = E_P ln(P/Q)（反方向）σ_Q² = ½(σ₁² + σ₂²)（方差平均）σ_Q ≈ 10/√2

注意：变分解给出的 σ_Q ≈ √2 几乎不理会那个大的方向（σ₁ = 10）——它把近似分布缩到了最窄的方向上。

为什么这个方向性很重要（MacKay 的对照）
"a good variational approximation is more compact than the true distribution. In contrast, a good sampler is more heavy tailed than the true distribution. An over-compact distribution would be a lousy sampler with a large variance."

——变分要"窄"，采样要"重尾"，两种角色要求相反。

所以绝不要把变分后验直接当提议分布喂给重要性采样（那正是"重尾缺失"的问题）。

其他几个易误读处

① 变分自由能给出的是 Z 的下界（自由能的上界），不是答案；只有 Q = 真后验时才取等。
② 平均场的分岔不是相变：平均场给二维伊辛的临界温度 T_c^mft = 4，而真值是 2.27（差近两倍）；而且它在 d = 1 也预测出分岔，而一维真实系统没有相变。MacKay 明确说："So the bifurcation at T_c^mft should not be described as a phase transition."
③ soft K-means 虽然能写成变分形式，但它对应 Q_θ(θ) = δ(θ−θ*)，而 delta 会让 ∫Q ln Q 发散。作者的批注是："[Using a delta function Q is not a good idea if our aim is to minimize F̃!]"
④ 变分的相对优势是与参数化无关（避开 MAP/Laplace 的基依赖），不是"更准"。

常见误读 把变分方法理解成"某种近似技巧"。它有一个明确的偏向（偏窄），而这个偏向来自 KL 的方向选择——不是实现细节问题，而是方法本身的性格。用之前先问：我这次需要"窄"还是需要"重尾"？

模块 G · 两个"同一算法的多个名字"

第 16、25、26 章。同一件事在四个领域有四个名字，这是最容易造成混乱的地方。
G1L3核心概念
请说出和-积算法的四个名字，以及它与 min-sum 的差别。在什么图上它才保证正确？在有环图上 MacKay 的建议是什么？
展开参考答案
四个名字（MacKay 原话）
"Other names for the sum–product algorithm presented here are 'the forward–backward algorithm', 'the BCJR algorithm', and 'belief propagation'."

加上"和-积算法"本身就是四个：和-积 / 前向-后向 / BCJR / 信念传播。

（注意这四个名字来自四个不同领域：编码理论、隐马尔可夫模型、卷积码、图模型。这是它们看起来像不同东西的原因。）

与 min-sum 的差别
算法做法回答什么问题别名
和-积用 Σ 与 Π每个变量的边际（逐位解码）前向-后向 / BCJR / 信念传播
min-sum把 Σ 换成 min、Π 换成 +（代价形式）最可能路径（最可能码字）Viterbi

MacKay 用"旅程的代价是各段代价之和"来说明 min-sum：每条边赋代价 −log P(y_n|t_n)，然后找最短路。

两者不能互换（这是重点）

习题 25.4 的例子：似然为 (0.2, 0.2, 0.9, 0.2, 0.2, 0.2, 0.2)。

方法结果
最可能码字（MAP / min-sum）0000000
逐位解码（和-积）0010000——它根本不是一个合法码字

两者服务于不同的目标函数，所以答案不同，而且都"对"。

还有一个复杂度事实：MAP 码字解码对一般线性码是 NP-complete 的。MacKay 的评论很精辟："限制到 MAP 问题上未必让任务变简单，只是让答案更简短好报。"

在什么图上保证正确

只有在树上（无环）才保证给出正确的边际。

在有环图上，MacKay 的诚实陈述是："不一定收敛，且肯定一般不会算出正确的边际函数"。

有环图上他的建议（这段很典型）
"However, the most amusing way of handling factor graphs to which the sum–product algorithm may not be applied is, as we already mentioned, to apply the sum–product algorithm! We simply compute the messages for each node in the graph, as if the graph were a tree, iterate, and cross our fingers."

——这就是 loopy message passing。而它之所以重要，MacKay 说得很清楚：它"仍然是一个具有巨大实际重要性的算法，特别是在稀疏图码的解码中"——Part VI 的 LDPC 与 Turbo 码都靠它。

有环图的精确解法是联结树算法：把变量聚合成块直到无环，代价随被聚合的变量数指数增长。

两条消息规则（第 26 章）

变量 → 因子：q_{n→m}(x_n) = Π_{m'∈M(n)\m} r_{m'→n}(x_n)

因子 → 变量：r_{m→n}(x_n) = Σ_{x_{m\n}} [ f_m(x_m) Π_{n'∈N(m)\n} q_{n'→m}(x_{n'}) ]

边际由汇入消息相乘读出：Z_n(x_n) = Π_{m∈M(n)} r_{m→n}(x_n)。

常见误读 ① 把"信念传播"当成一个独立的新算法——它是和-积的别名。
② 把 min-sum 和和-积混用去回答同一个问题。
③ 在有环图上用 loopy BP 却引用它为"我的近似是对的"的保证。它没有这个保证——它只是实践中很管用。MacKay 的"交叉手指"不是玩笑，而是一个诚实的认识论标注。
④ 另一个容易混的地方（Part III 的读者要注意）："belief propagation"这个名称第 25 章才出现，"factor graph"第 26 章才定义；第 16 章只有 message passing / sum-product / min-sum。所以第 16 章不是"信度传播那一章"。

模块 H · 应用与连接

这本书最有趣的地方在于它把同一套工具用在完全不同的对象上。
H1L4跨域
第 19 章问"性为什么存在"。请说明 MacKay 如何用信息获取速率回答这个问题。核心结论是什么？它在什么条件下不成立？
展开参考答案

这是全书最出乎意料的一章——它用信息论的框架讨论演化生物学。

第一步：教师信号极窄

自然选择是"教师"，但它的教学信号每个个体只有几个比特（后代多少），信息量至多每个后代 1 比特（谁存活到生育）。而且信号不告诉生态系统是哪些缺陷导致后代少，且高度冗余（相似的不适个体因相似原因失败）。

第二步：大数字的欺骗性

人类与猿分歧约 400 万年前、每代 10 年 ⟹ 约 400 000 代。种群 10⁹、每个体"几个比特" ⟹ 约 8×10¹⁴ 比特。

但 MacKay 指出自然选择不擅汇总，并引 John Maynard Smith 的论证：

"If the population size were twice as great, would it evolve twice as fast? No, because natural selection will simply be correcting the same defects twice as often."

（如果种群规模翻倍，演化会快一倍吗？不会，因为自然选择只会把同样的缺陷纠正两次。）

于是无性繁殖的信息获取速率与种群规模无关，约每代 1 比特 ⟹ 猿与人只能差约 400 000 比特，而人类基因组有 6×10⁹ 比特。

第三步：两个核心结论
繁殖方式信息获取速率可容忍突变率允许的基因组大小
无性约 1 比特/代（与种群规模无关）约 1/G约 1/m
有性可达 √G 比特/代约 1/√G（高 √G 倍）约 1/m²
机制：性产生变异而不降低平均适应度

这是关键洞察。两个适应度均为 fG 的亲本交配，孩子适应度的均值 = 亲本的适应度。

为什么？双亲皆良的位约 f²G 个；仅一方良的位约 2f(1−f)G 个（孩子以公平硬币从父母中取）。所以孩子适应度服从均值 fG、方差 f(1−f)G 的高斯。

而突变产生的变异必然伴随平均适应度下降。——这就是性相对于突变的关键优势：它以不损失均值的方式提供变异。

由此 dF̄/dt ≃ η√(f(t)(1−f(t))G)，解出 f(t) = ½[1 + sin(η(t+c)/√G)]——理想系统在有限时间 (π/η)√G 代内达到 f = 1。

模拟（G = 1000、N = 1000、f(0) = 0.5）：仅靠性约 80 代达到满适应度，"理论曲线拟合得非常好"；靠突变需要 350–1600 代。

"雄性成本"与性的稳定性

性的著名障碍是雄性成本：每两个经性产生的后代平均一个是不能生育的雄性，而孤雌母亲可以生两个克隆。所以"性为什么没被孤雌淘汰"是个真问题。

MacKay 的模拟结果（G = 1000，最有利于孤雌的参数）：

• 学习阶段孤雌群体短暂出现，两三代内消失
• 已达最高适应度后：若突变率低（mG = 1），孤雌可以接管；若 mG = 4，则永远无法接管

原因很漂亮：有性种群的适应度"宽度"约 √G，略高于平均的突变孤雌群体在约 1/(m√G) 代后跌到有性同胞之下——只要种群足够大、能有部分有性个体存活这么久，性就不会消亡。

不成立的条件（这部分很重要）

① 种群太小：一些比特冻结在劣态（"搭便车者" hitchhikers），齐性假设失效。实验发现只有 N ≲ √G 时理论才拟合很差。而且"盲眼钟表匠的决定"每代至多 2N 比特（指定 2N 个孩子中谁繁殖）。Baum et al. (1995) 建议为避免搭便车者应取 N ≈ √G(log G)²。
② 依赖加性适应度这一关键假设（F(x) = Σx_g）。MacKay 用 Baldwin 效应与"演化偏好弱交互表示"来辩护。
③ "8×10¹⁴ 比特"是总选择信号量（含巨大冗余），不是净信息量。净信息量用 I = Σ_g log₂(2f_g)，约等于适应度增益的两倍。

他的总结句
"In summary: Why have sex? Because sex is good for your bits!"

他还给了一个自我限定："性的相对收益仍将按 √G 缩放。只有在很小、近交的种群中性的收益才会被削弱。"

常见误读 把这一章读成"性必然胜出"。结论是条件性的：孤雌者在学习阶段被超越，但在高突变率下永远无法接管，只在已达适应度上限 + 低突变率 + 种群足够大时才可能反超。
另外注意 MacKay 的惋惜：Kondrashov（1988）的确定性突变假说早就指出了这一点，但该模因"并未在演化研究界传播，仍有许多论文把性的普遍存在视为需要复杂机制解释的谜"。这一章本身就是"信息论工具被另一个领域忽略"的一个例子。
H2L3跨域
第 18 章用填字游戏和破译 Enigma做了两件事。它们分别是什么？"ban" 和 "deciban" 是什么单位？
展开参考答案
第一件事：填字游戏给出语言冗余度的界

填字规则定义了一个受约束信道。如果存在大量合法填字，那么信道容量 > 0——而这给出语言冗余度的界：

• 无冗余（完全随机）⟹ 任意字母组合都合法 ⟹ 填字极容易
• 高冗余 ⟹ 填字极难

他用 Wenglish（第 4 章那个人造语言，W = 2¹⁵ = 32768 个长度 5 的词）把它定量化。定义 H_W ≡ log₂W / (L+1)（每个字符的平均信息量），然后得到两种填字类型的阈值：

填字类型特征阈值
A 型（美式）每行每列都是 ≥2 长度的词，每字母同属横竖两词H_W > ½ · (L+1)/L · H₀
B 型（英式）词与单字符混合，每字符至少属一词H_W > ¼ · (L+1)/L · H₀

取 H₀ = 4.2 比特、W = 4000、L = 5：B 型条件满足，A 型只是刚刚满足——这解释了"A 型填字常用更冷僻词"的经验。

他还顺便指出一个语言事实："Crosswords are not normally written in genuine English. They are written in 'word-English'."（填字游戏用的不是真正的英语，是"词英语"。）

第二件事：Banburismus —— Enigma 是一场巨大的贝叶斯推断

Enigma 的设置约 8×10¹² 种。Good 的原话是："it was therefore necessary to find about 129 decibans from somewhere."（因此必须从某处榨出约 129 分贝。）

机制：Enigma 实现的是连续变化的置换密码，在海量消息中，两台机器在发某字符时处于同一状态的概率是可观的，而且此后一直同步——这些相关性提供证据。

匹配概率 m = Σpᵢ²（英/德语约 m ≈ 2/26，随机语言是 1/26）。每次匹配提供 log(mA) 的证据，每次不匹配提供 log((1−m)A/(A−1))。

MacKay 在这里把三件事串起来了：填字游戏是受约束信道（信息论）；Zipf 分布与 Dirichlet 过程是语言模型（统计学）；Banburismus 是证据累积（贝叶斯推断）。三者在数学上是同一套东西。

证"几乎任何随机码都很好"证"几乎任何线性码都很好"

线性码是有结构的（可以用生成矩阵 G 和校验矩阵 H 描述，编解码是线性代数），所以比"随机码"更接近可实现的东西。MacKay 说这个证明"比第 10 章更有构造性"。

证明的关键：分析一个次优但可分析的译码器

核心是典型集译码器。校验子 z = Hr = Hx 只依赖噪声；译码就是求最可能的 x 使 Hx = z。

误差分两部分：

误差来源处理
(I) 真噪声不典型概率随 N → ∞ 趋零
(II) 典型噪声与别的典型向量撞同一校验子用 union bound + 对 H 求平均：⟨[Hv=0]⟩ = 2^(−M)

得到 P̄^(II) ≤ (|T|−1) · 2^(−M) ≤ 2^(NH(X)) · 2^(−M)，于是误差趋零当且仅当 H(X) < M/N，即 R < 1 − H(X) = 1 − H₂(f)。

——这就是容量。

源编码那一侧

同一个式子反过来读：给定二进制源熵 H(X) 与所需压缩率 R > H(X)，存在线性压缩器 x → z = Hx mod 2（速率 M/N = R）与近乎无损的解压器。

而且这个结论对任何可定义典型集的各态历经源都成立——包括有记忆源、时变源。这比第 4 章的 i.i.d. 假设宽松得多。

MacKay 指出这个方法可以推广到 LDPC 码，只需近似期望重量枚举函数。（这就把第 14 章与 Part VI 连起来了。）
